# Wallet — Static SaaS Landing Page

Desktop-first static HTML/CSS/JS implementation based on the supplied design screenshots.

## Structure

- `index.html` — semantic page structure
- `css/style.css` — layout, components, responsive rules, animations
- `js/script.js` — reveal-on-scroll, smooth navigation, newsletter interaction
- `assets/johnny-avatar.jpg` — locally cropped avatar from the supplied reference screenshot

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy to Vercel

1. Create a new GitHub repository and upload this folder.
2. In Vercel, choose **Add New Project** and import the repository.
3. Keep the framework preset as **Other** / static site.
4. Leave Build Command empty.
5. Set Output Directory to `.` if prompted.
6. Deploy with a generic project name such as `wallet-ui-demo`.
